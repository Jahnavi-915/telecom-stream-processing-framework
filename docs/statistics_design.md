# Statistics Design

## Objective

Collect performance and synchronization metrics from the POSIX Threads Producer-Consumer prototype.

## Metrics

### Frames Produced

Total number of frames generated by the producer.

### Frames Consumed

Total number of frames processed by the consumer.

### Buffer Full Events

Number of times the producer was forced to wait because the buffer was full.

### Buffer Empty Events

Number of times the consumer was forced to wait because the buffer was empty.

### Execution Time

Total runtime of the application.

### Throughput

Frames processed per second.

### Buffer Utilization

Average occupancy of the shared buffer during execution.
